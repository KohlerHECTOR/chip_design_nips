\begin{abstract}
Computer chips ought to be as small as possible for cost efficiency.
The problem of minimizing chip size while preserving the chip's functionality has been studied through the prism of and-inverter graphs (AIGs), since any Boolean function can be represented by an AIG.
Because the complexity of AIG size minimization is unknown---it is an instance of the minimum circuit size problem, which lies in NP but is not known to be NP-hard---no procedure returns optimal AIGs at the sizes of interest, and there is therefore no supervision signal in the form of optimal AIGs to imitate.
Reinforcement learning, and more generally planning, have been used to minimize AIGs in the absence of such a signal.
Contemporarily, graph representation learning has been applied to train machine learning models to perform tasks on graph data.
More recently, those two technologies have been combined and reported to outperform state-of-the-art logic synthesis heuristics, but the relative importance of graph representation learning in those methods remains unknown.
Is graph representation learning useful when minimizing and-inverter graphs with reinforcement learning? 
\end{abstract}


\section{Introduction}
A circuit that computes a given Boolean function with fewer logic gates occupies less area and is cheaper to manufacture~\cite{economy}.
Given a Boolean function, logic synthesis methods~\cite{resub,resyn,rewriting} are used to find a small circuit that computes it.
Because every Boolean function can be represented with AND and NOT gates only, logic synthesis methods represent circuits with and-inverter graphs (AIGs) which nodes are AND gates and edges can invert incoming bits.

However, finding the smallest AIG encoding a given Boolean function is an open problem.
It is an instance of the minimum circuit size problem, which lies in NP but is not known to be NP-hard~\cite{nphard}, and which is related to Graph Isomorphism~\cite{graphiso}.
In practice, AIGs are reduced by applying sequences of heuristics that rewrite the graph while preserving functional equivalence.
Many such heuristics are implemented in the \texttt{ABC}~\cite{abc} software.
Choosing the best heuristics sequence is a search problem.

In the absence of exact solvers, machine learning, such as supervised learning, has been applied to AIG minimization~\cite{graphbench}. 
However it suffered from two major weaknesses: first, the supervision signal to train from could be a suboptimal AIG since no exact solver exists, and second, graphs generative models are still quite limited~\cite{graphbench}.
Successful machine learning approaches are unsupervised ones that only require a scalar signal, often the size of a given AIG which is cheap to obtain: Bayesian optimization~\cite{bayes}, multi-armed bandits~\cite{flow-bandits}, reinforcement learning (RL)~\cite{rl-logic1,rl-gnn1} and Monte Carlo tree search~\cite{gnn-mcts}.
Contemporarily, graph representation learning has been applied to train models on graph data, and circuits are graphs: task-agnostic encoders built specifically for AIGs are now available~\cite{deepgate,polargate,funcgnn,chipgrl}.
The two lines of work have since been combined.
Several of the methods above encode the current AIG with a graph neural network rather than with a fixed set of summary statistics~\cite{rl-gnn1,gnn-mcts,more-mcts}, and achieve reductions beyond the expert \texttt{ABC} heuristics.
The motivation is the same as the one behind the very first deep RL algorithm, which was designed specifically for Backgammon~\cite{td-gammon}: the state space of AIG minimization is huge and cannot be enumerated, so the value of a state has to be generalized from other states.
A learned representation of the circuit should carry structural information that statistics discard, and that is what should allow a deep reinforcement learning algorithm~\cite{ppo} to generalize to unseen circuits: ``I have seen a similar graph before, I should probably edit the AIG in a similar way to get good results''.

What those RL methods do not report is how much of their performance is attributable to the learned representation design. 
We are not aware of a study that isolates the contribution of the AIG encoder to RL training.
Our work reports such an ablation, in the fixed-horizon setting that~\citet{rl-gnn1} introduced and that later work reuses.
We keep that pipeline fixed---the Markov decision process, the policy and value heads, the training algorithm and the hyper-parameter grid---and vary only how the AIG is presented to the policy.
We show the following results.

\paragraph{Contributions:} First, we show that adding a graph convolutional network to the policy does not improve AIG minimization beyond a multi-layer perceptron (MLP) that reads graph statistics (number of nodes, of levels, \dots).
Second, we give a candidate explanation: we compute, for AIG value prediction, the best error achievable by any model whose expressivity is bounded by the $1$-dimensional Weisfeiler-Leman refinement---which covers message passing networks---and find it no better than the one achievable from the graph statistics alone.
Next, we present existing AIG minimization methods.

\section{Related work}\label{sec:relwork}
\subsection{Combinational optimization}\label{sec:abc}
Combinational synthesis is a class of fast heuristics that reduce an AIG by rewriting it locally, and that work well in practice~\cite{rewriting,Mishchenko2006ScalableLS,resub}.
\texttt{ABC}~\cite{abc} is the reference implementation and is widely used both in industry and academia.
Throughout this paper we call \emph{primitives} its standard local transformations, \texttt{balance}, \texttt{rewrite}, \texttt{resub} and \texttt{refactor}, and \emph{heuristics} the named sequences of primitives it ships, such as \texttt{resyn2}.
Since no primitive is globally optimal, reduction is done by composing them into heuristics.
Hand-designed heuristics are the reference points against which learned methods are measured: \texttt{resyn}~\cite{resyn} applies \texttt{balance}, \texttt{rewrite}, \texttt{balance}, \texttt{rewrite}, \texttt{balance}.
Searching over sequences of primitives has been automated without learned circuit representations, with Bayesian optimization~\cite{bayes} and with multi-armed bandits~\cite{flow-bandits}.

\subsection{Graph representation learning for AIGs}
A separate line of work learns representations of circuits that are meant to transfer across circuits, rather than a policy for one circuit.
DeepGate4~\cite{chipgrl} is a foundation model that learns node embeddings of AIGs, supposedly useful for various downstream tasks on AIGs.
Three encoders from this line---DeepGate~\cite{deepgate}, PolarGate~\cite{polargate} and FuncGNN~\cite{funcgnn}---are among the models we evaluate in section~\ref{sec:value}.
\texttt{GraphBench}~\cite{graphbench} is, to our knowledge, the first AIG reduction benchmark built for methods that must perform on unseen AIGs.
It provides a training set of Boolean functions of varying input and output dimension and a disjoint test set, and it reports node reduction relative to the expert \texttt{ABC} heuristic: \texttt{resyn2}, \texttt{resyn2}, \texttt{dc2}, \texttt{resyn2rs}, \texttt{resyn2}, applied in that order.
Its main result is negative: given the AIG obtained by the naive construction from a truth table, specialized DAG generative models~\cite{directo,layerdag} do not preserve functional equivalence while reducing size.

\subsection{Reinforcement learning for AIGs}\label{sec:related-rl}
The works discussed in this section use similar AIG minimization formulations: the state observed by the trained policy is some representation of the AIG to minimize and the actions are \texttt{ABC} primitives (section~\ref{sec:abc}).

\citet{rl-logic1} formulate synthesis as an MDP whose states are vectors of AIG statistics---numbers of primary inputs and outputs, nodes, edges, levels and latches, and the proportions of AND and NOT nodes---whose actions are \texttt{ABC} primitives, and whose reward combines node count and level count.
\citet{rl-gnn1} keep \texttt{ABC} primitives as actions but encode the whole AIG with a graph convolutional network, alongside a small vector of statistics and recent actions, and reward the relative reduction in node count.
Episodes there have a fixed horizon and no early stopping, so the induced problem is a search over flows of fixed length.
This is the formulation we adopt, horizon included, and we state it in full in section~\ref{sec:mdp-instance}.
Both~\citet{rl-logic1} and~\citet{rl-gnn1} train with policy gradient methods~\cite{pg_sutton,reinforce,a2c,ppo}.
We are not aware of a value-based~\cite{watkins1992q,dqn} treatment, even though AIG editing is deterministic.
These methods report minimization performance beyond the \texttt{ABC} heuristics, but they are not designed to generalize: a policy is trained to reduce one AIG, so the training cost is paid again for every new circuit.
Search-based methods lift that restriction. AlphaSyn~\cite{gnn-mcts} and AlphaChip~\cite{chip} plan online and therefore apply to any circuits: every AIG edit choice requires a lookahead, and every lookahead step requires network forward passes.
However we argue that the cost of retraining a model is cheap compared to the cost of producing unnecessarily big chips at scale.
ABC-RL~\cite{more-mcts} sits in between: a policy pre-trained on other circuits guides the tree search, and its influence is scaled down when the circuit at hand is far from anything in the training set.
Two further formulations widen the setting rather than the state: ESE~\cite{more-rl} adds technology mapping operations to the action space and trains with PPO~\cite{ppo}, and CB-EVO~\cite{contextual-bandit} drops the sequential state altogether and treats the choice of primitive as a contextual bandit whose context is a set of circuit features.

\subsection{Graph reinforcement learning for other combinatorial optimization}\label{sec:otherco}
AIG reduction is an instance of graph structure optimization in the taxonomy of~\citet{graphrl}, who survey reinforcement learning applied to combinatorial problems on graphs and report that a graph neural network encoder is the common choice of state representation.
Within chip design the same combination is used for transistor sizing~\cite{transistors} and for macro placement~\cite{chip}; in both cases the encoder is motivated as the component that enables transfer to new circuits.
Next, we formulate AIG minimization as a Markov decision problem.

\subsection{And-inverter graphs minimization}\label{sec:aig-min}
Given an arbitrary Boolean function $f:\{0, 1\}^n \rightarrow \{0, 1\}^m$, the objective is to find an and-inverter graph that encodes $f$ with as few nodes as possible.

Section 3.2.1 from~\citet{graphbench} states that an and-inverter graph $\mathcal{G}:=(\mathcal{V}, \mathcal{E})$ is a directed acyclic graph of in-degree (fanin) at most two.
The node set is partitioned into input nodes of in-degree $0$, $\mathcal{V}^{in} := \{v^{in}_1,\dots,v^{in}_n\}$, AND nodes of in-degree two, $\mathcal{V}^{AND}:=\{v^{AND}_1,\dots,v^{AND}_k\}$, and output nodes of in-degree one, $\mathcal{V}^{out}:=\{v^{out}_1,\dots,v^{out}_m\}$; AIGs are therefore heterogeneous graphs~\cite{hetero}.
The edge set is $\mathcal{E}\subseteq \mathcal{V}\times \mathcal{V} \times \{0, 1\}$, with $0$ indicating direct transmission and $1$ indicating input negation (NOT).
For an input $\boldsymbol{x}\in \{0, 1\}^n$, values are assigned to input nodes, propagated through gate nodes (applying inversion where specified), and collected at output nodes to yield $\mathcal{G}(\boldsymbol{x})\in \{0, 1\}^m$.
Because the combination of AND and NOT is functionally complete, any Boolean function can be represented using only these two operations.

We write $\mathcal{G}_f:=\left\{\mathcal{G}: \mathcal{G} (\boldsymbol{x}) = f(\boldsymbol{x})\ \forall \boldsymbol{x}\in \{0, 1\}^n\right\}$ for the set of AIGs functionally equivalent to $f$.
AIGs are non-canonical representations of Boolean functions~\cite{fraig}---two different AIGs can represent the same function---so $|\mathcal{G}_f| > 1$ in general: e.g. the graphs of figure~\ref{fig:mdp} are functionally equivalent.
Given a Boolean function $f:\{0, 1\}^n \rightarrow \{0, 1\}^m$, we want to find ${\mathcal{G}}^\star \subseteq \underset{\mathcal{G}\in \mathcal{G}_f}{\operatorname{arg\ min}} |V|,$ the AIGs functionally equivalent to $f$ with as few nodes as possible.
The hardness of this problem is not known: it is an instance of the Minimum Circuit Size Problem~\cite{nphard}, a well-studied problem in NP that is not known to be NP-hard\footnote{\url{https://mcsp.work/index.html}}.

\subsection{Markov decision process}\label{sec:mdp-bg}
AIG minimization can be formulated as a sequential decision making task in which the environment is the current AIG, the actions are edits of that AIG, and the rewards are shaped to favor edits that remove nodes.
Formally, this is the problem of finding an optimal policy for a Markov decision process (MDP)~\cite{Bellman,puterman}.
An MDP is a tuple $\mathcal{M} = \langle S, A, R, T, T_0 \rangle$.
$S$ is a finite set of states representing all possible configurations of the environment (e.g. AIGs, or AIG statistics).
$A$ is a finite set of actions available to the agent (e.g. AIG edits).
$R: S \times A \rightarrow \mathbb{R}$ is a deterministic reward function that assigns a real-valued reward to each state-action pair (e.g. number of deleted nodes).
$T: S \times A \rightarrow \Delta(S)$ is the transition function that maps state-action pairs to probability distributions over next states $\Delta(S)$ (e.g. how graph edits change the AIG; here the transitions are deterministic).
$T_0 \in \Delta(S)$ is the initial distribution over states (e.g. a set of AIGs to reduce).

Given an MDP $\mathcal{M}\equiv\langle S, A, R, T, T_0 \rangle$, the goal of reinforcement learning is to find a policy $\pi: S \rightarrow A$ that maximizes the expected discounted sum of rewards {\small$J(\pi) = \mathbb{E}\left[\sum_{t=0}^{\infty} \gamma^t R(s_t, \pi(s_t)) \mid s_0 \sim T_0, s_{t+1} \sim T(s_t, \pi(s_t))\right]$}
where $0< \gamma\leq 1$ is the discount factor that controls the trade-off between immediate and future rewards.

We write $V^\star(s)=\mathbb{E}\left[\sum_{t=0}^{\infty} \gamma^t R(s_t, \pi(s_t)) \mid s_0 = s, s_{t+1} \sim T(s_t, \pi(s_t))\right]$ for the value of a state under an optimal policy, i.e. the discounted sum of rewards collected from $s$ by acting optimally.
$V^\star$ is the quantity a critic is trained to approximate in actor-critic methods, and the quantity a state representation must be able to distinguish states by; section~\ref{sec:value} uses it to measure what a representation can express, independently of any training procedure.

\subsection{Message passing neural networks}\label{sec:mpnn}
A message passing neural network (MPNN)~\cite{mpnn} attaches a vector $h_v^{(0)}$ to each node $v$, initialized from that node's features, and refines it over $k$ rounds: {\small$h_v^{(t+1)} = \phi^{(t)}\Big(h_v^{(t)}, \textstyle\bigoplus_{u \in \mathcal{N}(v)} \psi^{(t)}\big(h_v^{(t)}, h_u^{(t)}, e_{uv}\big)\Big),$}
where $\mathcal{N}(v)$ are the neighbours of $v$, $e_{uv}$ is an optional label on the edge between $u$ and $v$, $\bigoplus$ is a permutation-invariant aggregator, and $\phi^{(t)}, \psi^{(t)}$ are learned.
A graph-level vector is then obtained by pooling $\{h_v^{(k)}\}_{v\in \mathcal{V}}$ with a second permutation-invariant readout.
Architectures in this family differ only in the choice of $\psi$, $\bigoplus$ and $\phi$: GCN~\cite{gcn}, GIN~\cite{gin}, GAT~\cite{gat} and GraphSAGE~\cite{graphsage} are instances, and so are the AIG-specific encoders of appendix~\ref{app:trained}.
They also share a limitation. After $k$ rounds, two nodes that $k$ iterations of the $1$-dimensional Weisfeiler-Leman refinement assign the same color carry the same embedding~\cite{gin,wlgnn,graphtester}, so no network in the family can tell apart two AIGs that $1$-WL cannot.
Section~\ref{sec:bounds} turns this into a lower bound on the error of every such encoder.

Next, we present our methodology for studying the effect of MPNNs when using RL to train policies for AIG minimization formulated as an MDP.

\section{Methodology}\label{sec:method}%
\label{sec:mdp-instance}\label{sec:features}\label{sec:repr}\label{sec:rl-method}%
We use the same methodology as~\citet{rl-gnn1} who first combined graph convolutional networks and (deep) reinforcement learning for AIG minimization.
We use a similar MDP to theirs: the actions are the five \texttt{ABC} primitives $\{\texttt{balance},\ \texttt{rewrite},\ \texttt{rewrite -z},\ \texttt{refactor},\ \texttt{refactor -z}\}$, transitions are deterministic and every primitive preserves functional equivalence, so every reachable state stays in $\mathcal{G}_f$, and an episode applies exactly $H = 20$ of them to the AIG $\mathcal{G}_0$ to reduce, which makes the induced optimization a search over flows of length $20$ from a five-letter alphabet.
The reward differs slightly: writing $n_t$ for the number of AND nodes after $t$ actions, $R(s_t, a_t) = 1 - n_{t+1}/n_0$ is issued at every step, so with $\gamma = 1$ we optimize node count alone---the objective of section~\ref{sec:aig-min}---and not the multi-objective reward of~\citet{rl-logic1}.
Unlike~\citet{rl-gnn1}, we use PPO~\cite{ppo} to train policies instead of REINFORCE~\cite{reinforce} since the former is the more modern and state-of-the-art learner.

The policies we train always read a feature vector $x_\mathcal{G} \in \mathbb{R}^{|A|+5}$ holding the recent history of the actions taken so far, the AND and level counts of the current and previous AIG relative to $\mathcal{G}_0$, and the normalized time step: this is the same as in ~\citet{rl-logic1,rl-gnn1}.
This feature vector carries no AIG structural information, since two AIGs with the same size, depth and recent actions history are indistinguishable to it.
The key novelty of~\citet{rl-gnn1} is to feed the policy a graph convolutional network~\cite{gcn} reading the AIG and pooling it into a graph-level vector concatenated with the aforementioned feature vector $x_\mathcal{G}$.
This GCN addition has since then been built upon (cf. section~\ref{sec:related-rl}) but never ablated against e.g.~\citet{rl-logic1}.
Ablating the GCN, which is the focus of the following sections, matters because while it may increase performance, it certainly adds memory and time overheads.

\subsection{Results}
Figure~\ref{fig:rl-main}(a) shows that a tuned PPO learns to minimize an AIG
independently of the policy architecture, reaching a median performance $6\%$ below the
\texttt{resyn2} logic synthesis heuristic~\cite{resyn}.
Figure~\ref{fig:rl-per-benchmark} in appendix~\ref{app:curves} breaks the same runs down by benchmark and the observation holds, and
table~\ref{tab:rl-ands} reports the AND counts those runs reach.
Pooled over the ten benchmarks, last row of figure~\ref{fig:rl-main}(b), the GCN policies do end between
$0.74\%$ and $0.96\%$ below the MLP policy with confidence intervals excluding zero, and
the best GCN policies produce the smaller circuits on eight to nine benchmarks out of
ten. The effect is nonetheless marginal: it is not larger than what
re-running the baseline with different seeds produces (grey band), only six of the
forty encoder-benchmark comparisons have a confidence interval entirely below zero,
and in absolute terms the best GCN saves a median of $11$ AND gates per benchmark,
from none at all on \texttt{C6288} to $57$ gates on
\texttt{bc0}. Most importantly, figure~\ref{fig:rl-main}(c) shows the gain does not increase with encoder size: $2{,}496$ added parameters improve performance as much as $107{,}968$.
We repeated the experiment on the $100$ AIGs ($106$ to $46{,}977$ AND gates) of the 2026 IWLS programming
contest\footnote{\url{https://github.com/alanminko/iwls2026-ls-contest/}}. The picture there is the same in sign and magnitude,
$0.3\%$ to $0.7\%$ below the MLP (appendix~\ref{app:ex}).

Next, we ask why the gains from GCN policies are so marginal, despite the GCN being a representation specialized for graphs and the MLP reading only graph statistics and a short history of recent actions.

\section{Why does graph representation learning improve so little over MLPs?}\label{sec:value}
The previous section compares encoders inside one algorithm, so a null result there could be a property of that algorithm rather than of the representations.
We therefore ask a question that does not involve a training algorithm at all: how well can the optimal value $V^\star$ of a state (cf. section~\ref{sec:mdp-bg}) be predicted from what a given class of models is able to see?
This kind of empirical analysis of graph representations, in particular of MPNNs (cf. section~\ref{sec:mpnn}), has been carried out for graph-level regression tasks other than value prediction in~\citet{graphtester}.

\subsection{Building a dataset}\label{sec:dataset}
Computing $V^\star$ exactly is out of reach: the tree of flows over the five primitives of section~\ref{sec:method} has $5^H$ leaves, and every edge of it costs one \texttt{ABC} call on the full circuit.
We therefore estimate it by sampling both the states and the continuations from them.
A state is the AIG obtained by applying to the benchmark $\mathcal{G}_0$ a uniformly random flow of length $L\sim\mathcal{U}\{2,\dots,10\}$; we draw $1{,}000$ such states per benchmark and store each one both as an \texttt{.aig} file and as the statistics $x_\mathcal{G}$ of section~\ref{sec:features}, so that every model class of section~\ref{sec:bounds} is evaluated on exactly the same states and the same targets.
From each state $s$ we then run $M = 100$ independent rollouts of $8$ further uniformly random primitives and keep the best AND count reached, $\widehat{V}(s) = \min_{j \leq M} n^{(j)}(s)$, an upper bound on the minimum over the $5^8$ flows of length eight that approaches it from above as $M$ grows.
A key difference to $V^\star$ should be kept in mind: $\widehat{V}$ truncates the horizon at eight steps instead of the $H=20$ of the reinforcement learning experiments, so our targets approximate the value of an eight-step-to-go problem, and the bounds of section~\ref{sec:bounds} are lower bounds on the error of predicting \emph{that} quantity.
The procedure is repeated with ten seeds per benchmark on the same ten AIGs as in section~\ref{sec:rl-exp}, and the figures of this section report over those ten repetitions.
The sampler is degenerate on two of them, reaching only two distinct values of $\widehat{V}$ on \texttt{C6288} and six on \texttt{C1355}: we exclude \texttt{C6288} and report over the remaining nine benchmarks, flagging \texttt{C1355} wherever it appears.

\subsection{Theoretical lower bounds on the prediction error}\label{sec:bounds}
A model that cannot distinguish two states must assign them the same prediction, so a class of models partitions the state space and its best achievable squared error is that of the predictor returning, for each part, the mean target over that part.
No model in the class can beat that error, regardless of its size, its training procedure or its optimization.
This is the protocol of \texttt{Graphtester}~\cite{graphtester}, which measures the theoretical boundary of MPNNs (cf. section~\ref{sec:mpnn}) on a given dataset rather than the performance of one trained instance; we reimplement it for the target of section~\ref{sec:dataset} and for four representations, ordered by what they can see: the number of nodes $|V_\mathcal{G}|$ alone, which is what a $0$-layer message passing network reduces to; the pair $(|V_\mathcal{G}|, d_\mathcal{G})$, with $d_\mathcal{G}$ the logic depth reported by \texttt{ABC}; the engineered statistics $x_\mathcal{G}$ of section~\ref{sec:features} in full, the action histogram included, which is exactly what the MLP baseline of section~\ref{sec:method} reads; and the $1$-WL coloring of the AIG, which upper bounds the separating power of every architecture of section~\ref{sec:mpnn}.
Comparing the last two is the question of this section: what a learned encoder could express, against what the statistics already express.
They are incomparable rather than nested---only the current size and depth entries of $x_\mathcal{G}$ are functions of the current AIG, the previous step's size and depth, the normalized time step and the action histogram being episode history that no encoder of the current graph can recover---so the $x_\mathcal{G}$ bound may fall below the $1$-WL bound without contradicting it, and a policy that reads both, as algorithm~\ref{alg:graphppo} does, is bounded by neither alone.
Besides the squared error, which we normalize by the variance of the target, we report how well each class can \emph{order} states, with Spearman's $\rho$, Kendall's $\tau$ and the weighted $\tau$, since a critic that ranks successors correctly is useful even when its absolute errors are large.
The bounds are computed in sample, so a partition fine enough to isolate every state would drive the error to zero regardless of whether the representation carries any signal about $\widehat{V}$; we control for this by recomputing every bound with the targets randomly permuted across states, which leaves the partition intact and destroys the association.
Every bound we report sits $11$ to $474$ times below its shuffled-label counterpart, depending on the benchmark, and the two partitions we compare are of nearly equal granularity, at $865$ parts for $x_\mathcal{G}$ and $860$ for $1$-WL out of $1{,}000$ states on average, so neither class is merely memorizing the targets nor given more degrees of freedom than the other.
Appendix~\ref{app:bounds} details how the partitions are computed.

\subsection{Results}
A $k$-layer MPNN separates graphs at most as finely as $k$ iterations of
$1$-WL, so grouping states by their $1$-WL color and predicting each group's
mean $\widehat{V}$ gives an error no MPNN can beat; the same construction bounds a
$0$-layer network, a $(\text{size},\text{depth})$ model, and a model seeing the
MLP's features $x_\mathcal{G}$. From figure~\ref{fig:bounds}, we observe that message passing is worth a great deal over
global descriptors: the bound falls from $0.02$--$0.64$ of the target variance
for node count alone, to $1.1\times10^{-3}$--$0.24$ once depth is added, and to
$3\times10^{-4}$--$1.2\times10^{-2}$ for $1$-WL. It is worth nothing over
$x_\mathcal{G}$. On eight of the nine benchmarks the $x_\mathcal{G}$ bound is
the \emph{lower} of the two, at $0.73$ to $0.99$ times the MPNN bound; only
\texttt{C1355} goes the other way, where message passing is better by $1.93
\times$. The ordering is stable within a dataset: paired by seed,
$x_\mathcal{G}$ is lower on all ten seeds of six benchmarks and on seven and
eight of ten for \texttt{dalu} and \texttt{C7552}. For ranking the two classes
are indistinguishable---weighted Kendall $\tau \geq 0.97$ for both on every
benchmark, with $x_\mathcal{G}$ ahead by at most $0.014$---while size and
depth alone reach only $0.60$--$0.99$.
Depth is irrelevant---the bound moves by at most $1.1\times10^{-3}$ between
$k=1$ and $k=50$, and edge direction and inverter bits change it by less than
$10^{-6}$ (appendix~\ref{app:depth}). \texttt{C6288} is excluded: its target
takes only two distinct values.

\paragraph{Limitations of the bounds.} Two restrictions should be read with the numbers above.
First, they hold over the state distribution of section~\ref{sec:dataset}---AIGs reached by uniformly random flows of length two to ten---and not over the states a trained policy visits, which are fewer and more correlated; a representation could be uninformative on the former and useful on the latter.
% Second, $\widehat{V}$ is a Monte-Carlo estimate, so part of its variance is sampling noise that no representation can predict.
% That noise raises every bound by roughly the same amount and therefore compresses the ratios between classes towards one, which works in favor of the negative conclusion we draw; the $1$-WL and $x_\mathcal{G}$ bounds being close is evidence that message passing adds little, but not proof that the noise floor is not what they are both close to.
Second, the $1$-WL argument covers message passing networks whose input is the AIG with node-type features, which is the setting of section~\ref{sec:repr} and of~\citet{rl-gnn1}.
It does not cover higher-order architectures, models given node identifiers or positional encodings, nor encoders whose node features are not a function of the graph alone---the simulation-derived features used by some AIG-specific models are an example, and for those the bound of figure~\ref{fig:bounds} is not binding.

\section{Discussion}\label{sec:discussion}
In section~\ref{sec:rl-exp}, we observed that training a graph representation in the form of a GCN policy does not improve RL-based AIG minimization over an MLP reading graph statistics and the last few actions.
In section~\ref{sec:bounds}, we approximated an upper bound on the performance of any MPNN predicting the state values $\widehat{V}$ of section~\ref{sec:dataset}.
Those bounds give a candidate explanation for that null result: for predicting $\widehat{V}$, the statistics $x_\mathcal{G}$ the MLP reads are as expressive as any MPNN on the states we sample.
On eight of the nine benchmarks the error achievable from $x_\mathcal{G}$ is the lower of the two, and for ranking states the two classes are indistinguishable, at weighted Kendall $\tau \geq 0.97$ for both.
Nothing a GCN could extract from the graph would then improve the value estimate the policy is trained against, and the reduction it buys would stay of the order we measure.
The bounds do show that message passing separates states far better than size and depth alone, so this is a statement about the specific comparison with $x_\mathcal{G}$, not about message passing being uninformative.

The practical consequence is that a graph encoder should not be assumed to pay for its parameters here: in this pipeline it buys under $1\%$ of AND count, and the statistics baseline should be run before it is adopted.
This is not a statement about graph representation learning for logic synthesis in general: our evidence covers one policy gradient algorithm, five \texttt{ABC} primitives and a fixed horizon.
Appendix~\ref{app:trained} reports a preliminary attempt to train actual graph models and AIG-specific models on these datasets; the models do not fit their training set, so we draw no conclusion from it.

\section{Future work}\label{sec:future}
Our results are restricted to the setting used: a policy gradient algorithm, five \texttt{ABC} primitives as actions, and the fixed horizon of section~\ref{sec:mdp-instance}.
Two of those choices---the algorithm and the action space---bear directly on how much a learned representation of the circuit could contribute, and relaxing them is where we would look next.

\paragraph{Other reinforcement learning algorithms.}
AIG editing is deterministic and its exploration problem is hard, a combination for which value-based algorithms~\cite{watkins1992q,dqn} are usually competitive, yet the existing work on AIG reduction surveyed in section~\ref{sec:relwork} is entirely policy gradient-based.
That distinction matters here rather than only for sample efficiency: a value-based agent acts by comparing the predicted values of successor states, so its behavior rests entirely on the quantity section~\ref{sec:value} measures, whereas in an actor-critic method the value estimate only shapes the advantage.
If the representation is the bottleneck anywhere, it should be there, and our experiments do not answer whether a graph encoder helps under such an algorithm.

\paragraph{The full \texttt{ABC} action space.}
Five primitives give the policy little to decide, and the states it can reach are the images of a handful of short sequences, which may be why the statistics of section~\ref{sec:features} suffice to tell them apart.
\texttt{ABC} exposes many more primitives.
With more primitives, reachable states might differ from one another in more ways, and a representation that sees the circuit rather than its summary would have correspondingly more to distinguish.
Rerunning both the ablation of section~\ref{sec:rl-exp} and the bounds of section~\ref{sec:bounds} over that action space would say whether our negative result is a property of AIG reduction itself or of the small action space it is usually given.

To conclude, we have proposed the first empirical study of graph representation learning in RL-based logic synthesis. We hope our work will help researchers design better RL algorithms for AIG minimization by choosing the right representations that help policies accurately distinguish valuable AIG states.

\subsection{Graph encoders and reinforcement learning}\label{app:rl-hp}

\paragraph{The environment.}
The MDP of section~\ref{sec:method} instantiates the MDP of section~\ref{sec:mdp-bg} with the five \texttt{ABC} primitives as actions, where \texttt{-z} enables zero-cost replacements.
Episodes start from $\mathcal{G}_0$ and last exactly $H = 20$ actions with no early stopping.
Because every primitive preserves functional equivalence, the problem of section~\ref{sec:aig-min} is never violated, only under-solved.
The reward is a level rather than a difference, so the return is maximized by an agent that keeps the AIG small throughout the episode and not merely at the end.
Our environment also implements a seven-action variant adding \texttt{resub} and \texttt{resub -z}, and the full \texttt{ABC} action space, neither of which is used in our experiments.

\paragraph{The observation.}
Writing $n_t$ and $\ell_t$ for the number of AND nodes and of levels after $t$ actions, the vector part of the observation is
{\small$$x_\mathcal{G} = \Big[\underbrace{\tfrac{1}{q}\textstyle\sum_{j=1}^{q}\mathbf{1}[a_{t-j} = a]}_{a \in A},\ \ \frac{n_t}{n_0},\ \frac{\ell_t}{\ell_0},\ \frac{n_{t-1}}{n_0},\ \frac{\ell_{t-1}}{\ell_0},\ \frac{t}{H}\Big].$$}
The first $|A| = 5$ entries are a normalized histogram of the last $q$ actions, with $q = 3$ like in~\citet{rl-gnn1}; the next four are the AND and level counts of the current and of the previous AIG, each divided by its value in $\mathcal{G}_0$ so that the vector is scale-free across benchmarks of very different sizes; the last is the normalized time step, which makes the finite-horizon problem Markov in the observation.
It is computed in a single pass over the graph and adds no parameters of its own.
The graph part of the observation is the AIG itself, as in~\citet{rl-gnn1}: nodes carry a one-hot encoding of their type among the six types \texttt{abc\_py} exposes, a directed edge runs from each fanin to the node it feeds, and edges carry no label.

\paragraph{The encoders.}
Table~\ref{tab:encoders} lists the four graph encoders of section~\ref{sec:method}: three at depth three with widths from $12$ to $128$, and one at depth five, so that depth and width are not confounded.
Each runs the message passing rounds of section~\ref{sec:mpnn} over the AIG and pools the node embeddings into a graph-level vector concatenated with $x_\mathcal{G}$ before the policy and value heads.
The baseline uses no encoder at all and reads $x_\mathcal{G}$ alone through a multi-layer perceptron.

\paragraph{Training.}
Policies are trained with the PPO implementation of \texttt{stable-baselines3}~\cite{sb3} with $\gamma = 1$, the horizon being finite and fixed, and the encoder is trained end to end with the policy and value heads rather than pre-trained or frozen.
Eight environments run in parallel and each contributes $20$ steps per update, so an update is computed from $160$ transitions and a single episode spans five updates; $8{,}000$ environment steps therefore amount to $N = 50$ updates.
After every update we evaluate the greedy policy for one episode, which is the quantity the learning curves report.
The policy and value heads are each two hidden layers of $256$ units and share the encoder of line~\ref{line:encode} of algorithm~\ref{alg:graphppo}.
Algorithm~\ref{alg:graphppo} states the resulting procedure, which we call \textsc{GraphPPO}: it is ordinary PPO with the encoder made explicit, the encoding of the current AIG being the only place where the five configurations we compare differ.

\begin{algorithm}[h]
\caption{\textsc{GraphPPO}. The encoder $f_\theta$ is the only component that varies across the runs we compare; everything else is held fixed.}
\label{alg:graphppo}
\begin{algorithmic}[1]
\Require AIG $\mathcal{G}_0$ to reduce with $n_0$ AND nodes, encoder $f_\theta$, policy head $\pi_\theta$, value head $V_\theta$, action set $A$ of five \texttt{ABC} primitives, fixed horizon $H=20$, iterations $N$, epochs $K$, clipping $\epsilon$, entropy weight $\beta$, value weight $c$, step size $\eta$
\State $n^\star \gets n_0$
\For{$i = 1, \dots, N$}
  \State $\mathcal{D} \gets \emptyset$
  \For{each parallel environment}
    \State $\mathcal{G} \gets \mathcal{G}_0$
    \For{$t = 0, \dots, H-1$}
      \State $s_t \gets \big(f_\theta(\mathcal{G}),\ x_\mathcal{G}\big)$ \label{line:encode} \Comment{$f_\theta$ is a GCN, or is absent for the baseline}
      \State $a_t \sim \pi_\theta(\cdot \mid s_t)$, \quad $a_t \in A$
      \State $\mathcal{G} \gets \textsc{Abc}(\mathcal{G}, a_t)$ \Comment{deterministic, preserves functional equivalence}
      \State $r_t \gets 1 - |V^{AND}(\mathcal{G})| \,/\, n_0$ \Comment{relative size, issued at every step}
      \State $\mathcal{D} \gets \mathcal{D} \cup \{(s_t, a_t, r_t, \log\pi_\theta(a_t\mid s_t), V_\theta(s_t))\}$
      \State $n^\star \gets \min\big(n^\star,\ |V^{AND}(\mathcal{G})|\big)$
    \EndFor
  \EndFor
  \State compute returns $\hat R_t$ and advantages $\hat A_t$ from $\mathcal{D}$
  \State $\theta_{\text{old}} \gets \theta$
  \For{$K$ epochs over minibatches of $\mathcal{D}$}
    \State $\rho_t(\theta) \gets \pi_\theta(a_t\mid s_t)\,/\,\pi_{\theta_{\text{old}}}(a_t\mid s_t)$
    \State {\small$L(\theta) \gets \widehat{\mathbb{E}}_t\big[\min\big(\rho_t\hat A_t,\ \mathrm{clip}(\rho_t, 1-\epsilon, 1+\epsilon)\hat A_t\big) - c\big(V_\theta(s_t) - \hat R_t\big)^2 + \beta\,\mathcal{H}\big[\pi_\theta(\cdot\mid s_t)\big]\big]$}
    \State $\theta \gets \theta + \eta\,\nabla_\theta L(\theta)$ \Comment{gradients flow through $f_\theta$}
  \EndFor
\EndFor
\State \Return $n^\star$, the smallest AND count visited
\end{algorithmic}
\end{algorithm}

The grid of section~\ref{sec:rl-exp} crosses three learning rates ($10^{-4}$, $10^{-5}$, $10^{-6}$), three entropy coefficients ($0$, $0.01$, $0.1$) and five seeds, which with five encoders and ten benchmarks gives the $2{,}250$ runs reported there.
Twenty-six of those runs (eighteen \texttt{small}, eight \texttt{v.\,large}) stopped before the fiftieth update; we drop them rather than pad them, and requiring all five encoders to have completed a given (benchmark, learning rate, entropy, seed) cell leaves $424$ of the $450$ cells.

\section{Value prediction details}\label{app:value-hp}
\paragraph{The datasets.} The states of section~\ref{sec:dataset} are drawn by sampling $L$ primitives independently and uniformly from the five-element action set and running them in order; the graph models read the stored \texttt{.aig} file and the MLP reads the statistics $x_\mathcal{G}$ recorded at that point of the flow.
The state is reloaded between the $M$ rollouts.
Producing one dataset costs $1{,}000 \times (L + M \times 8) \approx 8\times 10^{5}$ \texttt{ABC} primitive calls per benchmark and per seed, which is why $M$ is lowered to $10$ on \texttt{C6288}, by far the most expensive circuit of the suite to rewrite.
Each of the ten seeds ($0$ to $9$) draws its own $1{,}000$ states and its own rollouts, and each resulting dataset is split at random into training, validation and test sets.
That the target is expressed in AND nodes rather than in returns does not affect the comparison between model classes: the map $n \mapsto 1 - n/n_0$ from AND count to the reward of section~\ref{sec:mdp-instance} is affine and order-reversing, all the errors we report are ratios to the variance of the target and are therefore free of its units, and the rank correlations we report are unchanged up to sign.

\paragraph{Training.} The models of appendix~\ref{app:trained} are trained in mini-batches of $16$ unless the batch size is itself searched over.
Each architecture's grid of $36$ configurations crosses three learning rates ($10^{-3}$, $5\times10^{-4}$, $10^{-4}$) with a width and a depth, or with the number of attention heads for GAT and the polarity weight for PolarGate.
DeepGate is the exception, with $12$ configurations: its pretrained encoder is frozen, so only the two-layer head is tuned.


\subsection{Computing the bounds}\label{app:bounds}
For the size and the size-and-depth classes of section~\ref{sec:bounds} the partition is by exact equality of the descriptors.
For $x_\mathcal{G}$, the full feature vector is snapped to a grid of spacing $10^{-8}$ and states are grouped by equality of the snapped vector, so the model we bound and the MLP baseline of section~\ref{sec:method} see the same thing.
For message passing, we group states by their $1$-WL graph hash, computed with \texttt{networkx}'s~\cite{networkx} \texttt{weisfeiler\_lehman\_graph\_hash} at every number of iterations $k = 1, \dots, 50$, with each node labeled by its type.\footnote{The hash is a $16$-byte \texttt{blake2b} digest. A collision would merge two groups that $1$-WL separates and can only raise the reported value, so the bound would become conservative rather than optimistic; at $1{,}000$ graphs per dataset the probability of one is negligible.}
We bound four views of the AIG, which is what the four message passing curves of figure~\ref{fig:bounds} report: the undirected graph $\mathcal{G}$, the directed graph $\mathcal{G}^\rightarrow$ in which refinement follows the fanin relation, and the two variants $\mathcal{G}^e, \mathcal{G}^{\rightarrow e}$ that additionally label each edge with its complement bit, so that inversion is visible to the refinement rather than only through node types.
Errors are divided by $\max(1, \operatorname{Var}\widehat{V})$; in AND-node units the variance is orders of magnitude above one on every benchmark, so the clamp never binds and the reported quantity is the plain normalized error.
Rank correlations are computed at $k = 50$ refinement iterations.
The permutation control uses $25$ permutations per dataset, $8$ on \texttt{mainpla} and \texttt{C6288}, and is applied to the rank correlations as well, where the null is the correlation between $\widehat{V}$ and a random permutation of itself.

\section{Preliminary results: training models to predict $\widehat{V}$}\label{app:trained}
The bounds of section~\ref{sec:bounds} say what a representation \emph{could} express.
This appendix reports what models actually trained on the same datasets achieve.
We report it as preliminary: the graph models do not fit their training set, and we have not established whether this comes from the models, from our training protocol, or from the task itself, so none of the claims of the paper rest on it.

\paragraph{Setup.} We train eight regressors on the datasets of section~\ref{sec:dataset}.
Four are generic message passing networks---GCN~\cite{gcn}, GIN~\cite{gin}, GAT~\cite{gat} and GraphSAGE~\cite{graphsage}---taken from \texttt{PyTorch Geometric}~\cite{pyg}.
Three are AIG-specific: DeepGate~\cite{deepgate}, PolarGate~\cite{polargate} and FuncGNN~\cite{funcgnn}, each run from its authors' implementation.
The eighth is the MLP baseline of section~\ref{sec:method}, which reads $x_\mathcal{G}$ and no graph at all, and is the baseline the graph models have to beat.
All eight share the same head so that only the encoder differs: node embeddings are mean-pooled into one vector per AIG, which a two-layer ReLU network maps to a scalar.
GCN, GIN and GraphSAGE consume the six-way one-hot node type of section~\ref{sec:repr}; GAT, PolarGate and FuncGNN consume the three-way type (input, AND, inverter) of the DeepGate reader, with the inverter bit exposed as a signed edge feature, so that the models that were designed to use complementation receive it.
DeepGate is the one exception to end-to-end training: we load the pretrained encoder, freeze it, and train only the head on its mean-pooled functional embeddings, which is how it is meant to be used as a general-purpose circuit encoder.

Targets are $\widehat{V}$ divided by the AND count of the benchmark's initial AIG, so they lie in $(0, 1]$ and are comparable across circuits.
Each dataset of $1{,}000$ states is split $80/10/10$ into training, validation and test sets by a permutation seeded by the run seed.
Models are trained for $1{,}000$ epochs with Adam~\cite{adam} on the mean squared error.
Each architecture is given its own grid of $36$ configurations, and $12$ for DeepGate, whose frozen encoder leaves only the head to tune; the grids are in appendix~\ref{app:value-hp}.
The grid is run at seed $0$, the configuration with the lowest final validation error is selected, and that configuration alone is then rerun on the ten seeds we report; the seed selects the dataset, the split and the initialization together, so the ten repetitions are independent in all three.
We report test error normalized by the variance of the test targets, so that $1.0$ is the error of predicting the mean.

\paragraph{Results.} All seven graph models land between $0.90$ and $1.74$ times the target variance---at or above the constant predictor---while the MLP reaches $0.47$ at the median.
Their training error is also $\approx 1$, so this is a failure to fit rather than to generalize, and it leaves them two to three orders of magnitude above the bound of figure~\ref{fig:bounds} that their own architecture class admits.
The per-dataset validation curves of figure~\ref{fig:curves} show the graph models settling at the level of the constant predictor early in training and staying there.
A gap of that size between what the class can express and what training reaches is what makes us treat these runs as preliminary rather than as a result about the architectures.
